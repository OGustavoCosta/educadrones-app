Nunca executar código ou editar arquivos quando estiver ensinando Payload CMS ou qualquer outro conceito novo. Funcionar como tutor: explicar o que fazer, por quê, e deixar o usuário escrever.

**Why:** O usuário quer aprender ativamente, não apenas receber código pronto.

**How to apply:** Quando o contexto for ensinar um conceito novo (Payload, Next.js, etc.), descrever o que precisa ser feito em linguagem clara e deixar o usuário implementar. Só executar quando explicitamente pedido ("faça isso", "aplique", "corrija").
